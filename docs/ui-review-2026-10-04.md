# UI review — 4 October 2026

## Changes

- Demo Ask defaults to Auto reply language, external AI and selected demo-data sharing when
  configured. Opening the page never calls the provider. Before Send, the notice explains
  transfer/cost and both switches remain visible. Unavailable AI leaves both off.
- Compact chat settings, readable select height, example chips, one page scrollbar, expandable
  source facts and readable source timestamps. Ctrl/Cmd+Enter sends; Enter still makes a new line.
- Shared spacing, quieter cards, readable 18px body text, wrapping badges/actions, mobile header
  actions, keyboard skip link, current-page semantics and visible rating focus.
- Medicine summaries/actions stay visible; detailed evidence and courses expand on demand.
  Early-calving conditions and prototype/safety warnings remain visible.
- Treatment notes/milking overrides and supporting entry checks are expandable. Dashboard removes
  duplicate hero actions. Existing page separation and server permissions are unchanged.

## Bugs addressed

- Add cow now exits an edit; saving no longer restores the old edit-button label.
- Repeated saves are guarded on cow, event, feedback, account, schedule and medicine forms.
- Busy-label restoration preserves the original disabled state and tolerates repeated calls.
- Stale dry-off responses cannot overwrite the next selected cow/season; prior justification is
  cleared when the context changes.
- Treatment-date products no longer display a misleading predicted-calving warning.
- Corrections retain a culled cow reference; inactive medicine corrections are blocked visibly,
  not silently converted to an empty selection. Removing prior medicine evidence is not implicit.
- Failed correction-history loads and post-save history refreshes show useful messages.
- Clearing notes explicitly now clears SQLite notes, with an audited correction and unchanged
  medicine evidence/withholding result. This is the only application-server change.
- Chat context clearing cannot race a new send.
- Login rejects external/protocol-relative return URLs; logout failures stay visible.
- Hidden feedback rating inputs no longer extend the mobile page; the schedule task links to
  Milking plan, not Medicines.

## Verification and boundaries

- 290 automated checks passed (including 19 new UI regression tests), plus database integrity,
  foreign-key, index and ACVM reference gates.
- Local browser review of 14 main/detail/helper pages at desktop and phone breakpoints, including
  page overflow and console errors. The feedback overflow was reproduced, fixed and rechecked.
- Browser checks of default AI/language settings, simulated conversation, edit-to-add cow flow,
  and feedback submission/reset/results.
- All browser writes used a new temporary demonstration SQLite database. Provider replies were
  mocked, with no real API calls or credit used. These checks do not verify a live provider or
  production deployment. No production credentials were read or changed.
- Schema remains v9; no migration, medicine-reference import or milk-release calculation change.
- This remains a field-test prototype, not clinical certification or a milk-release authority.
