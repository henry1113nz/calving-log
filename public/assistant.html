How this works · 数据、权限和限制

The language model generates normal replies. When you consent to demo-data sharing, the server supplies a fresh herd summary and validates any read-only lookup the model requests. It cannot run arbitrary SQL or write records. Source links and expandable server facts appear below each answer, separate from the AI's wording.

Recent conversation is held in server memory for up to 30 minutes of inactivity, not saved into your farm database. New chat clears that conversation; refresh starts a new one. Changing sharing consent resets context so earlier record facts are not sent after you withdraw consent. No web search is connected. General answers and translations may be wrong; verify important claims.

Without external AI, simple local lookups still work, but free-form conversation and follow-ups do not. To confirm a calving draft, use the record helper; to record treatment, use Treatments.
